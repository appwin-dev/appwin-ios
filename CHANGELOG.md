# Changelog - SDK iOS Appwin

Les versions suivent le [versionnage sémantique](https://semver.org/lang/fr/).

Les quatre produits (`AppwinCore`, `AppwinSupport`, `AppwinCommunity`,
`AppwinNotifications`) sont livrés par un paquet unique et portent donc **la
même version**. C'est aussi la version des artefacts Android, Flutter et React
Native : ils se dépendent entre eux, et des versions désalignées produiraient
des combinaisons jamais testées.
